# 사용자 맞춤 채용공고 웹 (채용공고 트렌드 분석)

> 클라우드 기반 웹 개발 수업 팀 프로젝트 · 6조억

## 1. 프로젝트 소개

- **목표**: 구직자가 분야·직무별 채용 트렌드(인기 기술 키워드, 지역·경력 분포)를 확인하고, 관심 직무에 맞는 공고를 추천받는 웹 서비스
- **대상**: 일반 구직자 (IT / 전기·전자 / 디자인 분야)
- **데이터**: 사람인 Open API로 수집한 공고 정보
- **분석 방식**: 공고 본문이 아닌 API 제공 필드(기술 키워드, 직무, 지역, 경력, 급여) 기반 집계
- **배포**: AWS 서버 구축 후 웹으로 서비스

## 2. 주요 기능

| 기능 | 설명 | 담당 |
|---|---|---|
| 공고 수집 | 사람인 API로 공고 수집 (AWS Lambda + EventBridge 자동화 예정) | 인경 |
| 공고 목록 | 분야·직무·지역·경력 필터, 페이지네이션 | 해민 |
| 공고 상세 | 핵심 정보, 기술 키워드, 근무 위치 지도, 직무 내 키워드 순위, 원문 링크 | 해민 |
| 트렌드 분석 | 키워드 Top N, 주차별 키워드 추이, 지역·경력 분포 그래프 | 인경 |
| 맞춤 추천 | 관심 직무·지역·경력·키워드 일치 점수 기반 추천 + 추천 이유 | 인경 |
| AI 요약 | Gemini API로 통계 요약, 추천 이유 문장 생성 | 인경 |
| 소셜 로그인 | Google, 카카오 로그인 | 공동 |
| 마이페이지·북마크 | 관심 직무 설정, 공고 북마크 | 해민 |
| 방문 통계 | 페이지별 방문 수 | 공동 |

## 3. 기술 스택

| 구분 | 기술 |
|---|---|
| Backend | Python, Flask |
| Frontend | Jinja2 템플릿, Chart.js |
| 지도 | 카카오 지도 |
| 인증 | Authlib (Google·카카오 OAuth) |
| AI | Gemini API |
| 수집·배포 | AWS Lambda, EventBridge, EC2 (예정) |
| 데이터 저장 | 추후 연동 (현재는 mock 저장소) |

## 4. 시스템 구조

    사람인 API → 수집 (Lambda) → 저장소 → Flask 웹 서버 (EC2) → 사용자

- 모든 데이터 접근은 `repositories` 인터페이스를 거치며, 지금은 mock 구현체를 사용
- 저장소 구현체만 교체하면 DB로 전환 가능
